# Orchard Core Themes

Place custom Orchard Core themes here:

- `BaceVector.Theme.Marketing` – marketing site, pricing, blog, docs.
- `BaceVector.Theme.Portal` – tenant portal styling aligned with product brand.

Scaffold with:

```ps1
dotnet new octheme --name BaceVector.Theme.Marketing
```

After scaffolding, add `Manifest.cs` metadata and enable the theme via the Orchard Core admin UI.
